# Assets

- `wordmark-ink.svg` — wordmark for light surfaces (charcoal text, soft-gold separator dot).
- `wordmark-paper.svg` — wordmark for the dark accent surface (paper text, gold-300 dot).

Iconography uses [Lucide](https://lucide.dev) loaded via CDN. No icon set is bundled; this folder holds only the wordmark.

Wordmark anatomy: `Compound Income · OS` — Geist 600, `-0.01em` tracking. The center dot (`·`) is rendered in soft gold (`--gold-500` on light, `--gold-300` on dark) and is the only ornament permitted in the mark.
