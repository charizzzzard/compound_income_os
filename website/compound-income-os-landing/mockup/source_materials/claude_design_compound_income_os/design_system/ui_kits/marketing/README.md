# Marketing UI kit — Compound Income OS

Landing-page direction. Open `index.html` in the preview.

## Components

- `HeroAndNav.jsx` — `MarketingNav`, `Hero` (email-capture + CTA pair).
- `DashboardPreview.jsx` — `DashboardPreview` (dark accent surface KPI grid + dividend snowball sparkline + coverage panel + artifact strip).
- `Sections.jsx` — `ProblemSection`, `SolutionSection`, `PrinciplesSection`, `WorkflowSection`, `FeaturesSection`, `SpecialSections`, `JournalAndAudience`, `AccessSection`, `FinalCTA`, `Footer`.

## Sections shipped (per brief)

1. Navigation
2. Hero
3. Dashboard preview
4. Problem
5. Solution
6. Product principles (six)
7. Core features (eleven)
8. Monthly workflow (six steps)
9. Dividend snowball + SEC pipeline + Data quality (three-up)
10. Decision journal + Audience
11. Access / monetization (Core, Pro, Setup, Sponsors)
12. Final CTA on dark accent surface
13. Footer with full disclaimer

## Conventions used

- All copy is verbatim or close-to-verbatim from `source_materials/01_brand_strategy_and_copy.md`. No invented features.
- Status pills (`OK`, `PARTIAL`, `REVIEW`, `MISSING_DATA`, `INSUFFICIENT_HISTORY`) appear throughout the dashboard preview.
- Disclaimer block is always rendered in the footer.
- KPI numbers always in JetBrains Mono with tabular numerals.
- No icons in hero or KPI cards. Numbers carry the visual weight.
