# Monthly Portfolio Decision Brief Examples

These files are synthetic and sanitized reviewer-facing documentation artifacts.
They are not generated real portfolio outputs and do not represent private
holdings, broker exports, provider files, raw data, credentials, local paths,
tax lots, transactions, account values or operator decisions.

The examples show the expected Monthly Portfolio Decision Brief surface for
external review and Human Operator inspection:

- `monthly_portfolio_decision_brief_READY.example.*`: mandatory ranking evidence
  is available and optional review evidence is clean.
- `monthly_portfolio_decision_brief_REVIEW.example.*`: mandatory ranking evidence
  is available, while optional evidence contains visible `MISSING`, `STALE`,
  `UNKNOWN`, `REVIEW_REQUIRED`, `NOT_AVAILABLE` and `NOT_APPLICABLE` states.
- `monthly_portfolio_decision_brief_BLOCKED.example.*`: mandatory monthly
  ranking evidence is missing, so the surface stays `BLOCKED` and does not infer
  candidate rows, readiness or action.

When shown, `execution_mode`, `execution_mode_reason` and Data Freshness
`summary_counts` are synthetic upstream evidence fields preserved for reviewer
surface inspection. They are not calculated by the example files.

Paths under `examples/monthly_portfolio_decision_brief/synthetic_inputs/*`, when
shown inside example JSON, CSV or Markdown files, are illustrative
`source_artifact` references for the reviewer surface. They are not real
portfolio inputs and are not required generated fixtures unless a future patch
explicitly adds fixture files.

The examples are static by design. Real generated Monthly Brief outputs remain
local/generated by default:

- `data/processed/monthly_portfolio_decision_brief.json`
- `data/processed/monthly_portfolio_decision_brief.csv`
- `reports/<as_of_date>/monthly_portfolio_decision_brief.md`

Tracked examples do not imply production readiness, investment readiness,
broker/API integration, buy/sell automation or order execution. The Human
Operator remains final acceptance authority.
