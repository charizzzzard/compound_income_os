# Docs Drift Checklist

Use this checklist before consolidation commits and after patches that add
modules, workflows, generated artifacts, website material, or handoff behavior.

- New source file added?
- New CLI/module added?
- New `data/processed` artifact added?
- New report added?
- New config added?
- New handoff behavior added?
- New website/mockup material added?
- README affected?
- MODULE_CONTRACTS affected?
- OUTPUT_CONTRACTS affected, if present?
- HANDOFF_CONTRACT affected?
- CONTEXT_AND_ROADMAP affected?
- Private/local files documented as not-for-commit?
- Cleanup inventory updated?
- Handoff validation required for external review?
- Remaining docs drift findings fixed or explicitly accepted?
